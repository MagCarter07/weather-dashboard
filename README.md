# Weather Dashboard 🌤️

A responsive weather dashboard built with React and Tailwind CSS.

## Features

- Search weather by city
- Displays temperature, humidity, wind speed
- Weather icon display
- Error handling
- Responsive design

## Tech Stack

- React (Vite)
- Axios
- Tailwind CSS
- AccuWeather API

## Setup

1. Clone the repository
2. Run `npm install`
3. Add your API key in `.env`
4. Run `npm run dev`
